# 🛒 E-Commerce Behaviour Analysis

## 📌 Overview

This project focuses on analyzing **user behavior in an e-commerce platform** using real-world clickstream data.

The dataset captures how users interact with products through events such as:
- 👀 Product views  
- 🛒 Add to cart  
- 💳 Purchases  

The goal is to transform raw event data into meaningful insights and prepare it for machine learning models.

---

## 🎯 Objectives

- Perform data analysis using **Python, NumPy, and Pandas**
- Understand customer interaction patterns
- Clean and preprocess raw behavioral data
- Generate statistical insights
- Prepare dataset for ML models like:
  - Classification (purchase prediction)
  - Regression (spending prediction)
  - Clustering (customer segmentation)

---

## 📊 Dataset Information

- **Source:** Kaggle (E-commerce Behavior Dataset)
- **Type:** Clickstream / Event-based data  
- **Key Features:**
  - `event_time` → Timestamp of activity  
  - `event_type` → view / cart / purchase  
  - `product_id` → Product identifier  
  - `category_id` → Product category  
  - `brand` → Product brand  
  - `price` → Product price  
  - `user_id` → Unique user  
  - `user_session` → Session identifier
